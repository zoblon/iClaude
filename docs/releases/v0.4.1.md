## iClaude 0.4.1

The Desktop Extension now includes the new iClaude icon: an original terracotta cloud composed of organic radiating forms. The icon appears in Claude Desktop's extension installation and management interface when this package is used.

The repository also includes the transparent PNG logo, the original generation source, a matching English GitHub social preview with a stronger wordmark, and asset metadata with dimensions, SHA-256 hashes, typography and exact copy. Both READMEs link these files under `assets/`. The GitHub Social Preview setting uses the new image.

The package build checks that the icon inside the `.mcpb` archive matches `assets/icon.png` byte for byte. Asset notes explain the earlier graphic's Apple origin and the project's independence from Apple and Anthropic.

This release changes the visual identity and version number. Tools, permissions, extension identifier and runtime behavior are unchanged from 0.4.0. Install `icloud-mcp-0.4.1.mcpb` using the update steps in the README.
