## iClaude 0.4.0

iClaude can now work with **Apple Reminders** and **Apple Notes**. iCloud has no open interface for them, so iClaude controls the two apps on your Mac (JavaScript for Automation). Nothing leaves the Mac for this; no password is involved.

### New tools

**Reminders:** `list_reminder_lists`, `list_reminders`, `search_reminders`, `create_reminder`, `update_reminder` (checks the current title first), `complete_reminder` (up to 20, checks every title). Reminders are never deleted.

**Notes:** `list_note_folders`, `list_notes`, `search_notes` (title, optionally full text), `get_note` (plain text or Markdown, paged), `create_note` (Markdown or plain text, converted to safe HTML). Existing notes are never changed, moved or deleted, and notes locked with a password are only reported as locked.

### What to know

- **One-time macOS question:** the first use of each app makes macOS ask whether Claude may control Reminders / Notes. Answer OK. It can be changed in System Settings > Privacy & Security > Automation.
- The Mac has to be awake and Claude Desktop running; Reminders and Notes are started in the background when needed. On other systems than macOS the tools say so.
- Shared lists and folders: Notes tells whether a folder is shared, so `create_note` needs `shared_folder` for those. Reminders does not, so `create_reminder` only writes into a list you name or into the default list.
- A reminder's due date can be set and changed, but not removed (Apple's scripting interface cannot clear it).
- Please set `update_reminder` to require approval, in addition to the tools named in the README.

### Under the hood

- All scripts are fixed texts; input reaches them only as one JSON argument, never inserted into script text. A guard test proves that hostile input (quotes, line breaks, `do shell script`) executes nothing.
- New: CI badge, PRIVACY.md and SECURITY.md are linked from the README and the manifest names the privacy policy.
- Releases are now built and published by the release workflow from a tag.

Tested live against a real Mac with Reminders and Notes in dedicated test containers; locked notes and shared folders are covered by tests only.
